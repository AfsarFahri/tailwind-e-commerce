# 🛒 E-Commerce Website (Frontend Project)

A modern e-commerce frontend built with Tailwind CSS, designed to deliver a clean, responsive, and user-friendly shopping experience.
This project showcases structured layouts, a product grid system, and a minimal UI focused on usability and visual clarity.

---

## 🚀 Features

* ✨ Clean and modern user interface
* 📱 Fully responsive design (mobile, tablet, desktop)
* 🛍️ Organized product grid layout
* 🎯 Simple and intuitive navigation
* ⚡ Built using utility-first Tailwind CSS

---

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS

## ⚙️ Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/AfsarFahri/tailwind-e-commerce.git
   ```

2. Open the project folder:

   ```bash
   cd tailwind-e-commerce
   ```

3. Open `index.html` in your browser
